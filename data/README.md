# Data Sources and Owners

This document records the source, owner, and update frequency for files used by the assistant's data retrieval component.

## Data Inventory

| File | Source | Owner | Update Frequency |
|---|---|---|---|
| `README.md` | Project documentation | Project team | Updated when documentation changes |

## Notes

- **Source:** The original location or system from which the data originates.
- **Owner:** The person or team responsible for maintaining the file.
- **Update Frequency:** How often the file is reviewed or refreshed.
- Entries should be updated as the project's data sources are identified.

## Maintenance

Update this document whenever data files are added, removed, or changed.
