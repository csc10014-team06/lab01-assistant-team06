# UI Citation Specification

## Format Rules
- Every response generated by the assistant that references external data must display a citations/sources section at the end of the answer.
- Mandatory prefix: `Sources: <file_path>` for a single source, or an itemized bulleted list under `Sources:` when multiple sources are referenced.

---

## Mockup Examples

### Example 1: Single Source Lookup
**User:** Where is the Training Office?  
**Assistant:**  
> Training Office: room I.101, open Mon-Fri 07:30-16:30.  
>  
> *Sources: `data/offices.csv`*

---

### Example 2: Multi-source / Policy Answer
**User:** When does the library close and what is the fee policy?  
**Assistant:**  
> The Library closes at 20:00 on weekdays. Course retake fee is calculated according to Finance notice 26-07.  
>  
> *Sources:*  
> - `data/offices.csv` (Library hours)  
> - `docs/policies/tuition_fees.md` (Retake rate policy)
